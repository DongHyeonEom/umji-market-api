# 구현 현황

이 문서는 구현 여부와 현재 미구현 범위만 요약함.<br>
서비스별 API 계약·업무 흐름·세부 구현은 [서비스 문서](services/README.md), 계층·패키지 기준은 [architecture.md](architecture.md)를 기준으로 함.<br>
DB 현황은 [database.md](database.md)를 기준으로 함.<br>

## 구현된 영역

인증·계정·화면 접근 권한, 카탈로그·장바구니·재고, 운영, 주문·결제·배송, 파일, 알림의 API와 업무 처리를 제공.<br>
판매자 카탈로그·영업 배정·인센티브를 포함한 세부 기능과 흐름은 [서비스 문서](services/README.md)의 도메인별 기준을 따름.<br>

## 미구현 범위

- SMS 본인 확인 및 비활성·신규 계정 활성화 흐름
- 부분 주문 취소 및 배송 상태 이력
- 알림 delivery 이력과 운영자 실패 조회·재처리 API

세부 범위와 현재 동작은 각 서비스 문서에서 관리하며, 구현되지 않은 endpoint나 흐름은 제공 중인 기능처럼 기술하지 않음.<br>
